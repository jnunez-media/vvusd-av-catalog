# VVUSD Audio/Video Equipment Catalog

An interactive HTML flipbook of the Val Verde Unified School District Audio/Video
Equipment Catalog (2026–2027) — 89 items across Audio, Video, Peripherals, and
Miscellaneous categories, each with a photo, description, price, and direct
purchase links (B&H Photo Video, MarkerTek, Amazon).

**Live site:** enabled via GitHub Pages on this repo (see repo Settings → Pages).

Built with plain HTML/CSS/JS — no build step, no external dependencies. Open
`index.html` directly, or serve the folder with any static file server.

Presented as a realistic two-page book spread (like a printed catalog) with a
3D page-turn animation, a dark surrounding stage, and a bottom toolbar for
zoom, page thumbnails, a page slider, and fullscreen. Navigate with the
on-screen arrows, the corner click-zones, the keyboard arrow keys, or by
swiping on touch devices. The Table of Contents links jump straight to each
category.
